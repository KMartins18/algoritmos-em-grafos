# 🕸️ Algoritmos em Grafos (ARA0175)

Repositório destinado ao armazenamento dos códigos práticos e implementações desenvolvidas para a disciplina de Algoritmos em Grafos.

## 🚀 Sobre
Este repositório contém as implementações em Python dos principais algoritmos de travessia, caminhos mínimos e árvores geradoras mínimas estudados ao longo do semestre.

## 📂 Algoritmos Implementados
Os seguintes algoritmos já estão disponíveis e funcionando:

* **Busca em Largura e Profundidade** (`busca_profundidade_largura.py`)
* **Algoritmo de Dijkstra - Não Orientado** (`dijkstra_nao_orientado_corrigido.py`)
* **Algoritmo de Dijkstra - Orientado** (`dukstra-orientado_corrigido.py`)
* **Algoritmo de Kruskal** (`Algoritmo_Kruskal_corrigido.py`)
* **Algoritmo de Prim** (`algoritmo_prim_corrigido.py`)
